"A control here (a piston, a button, a drawstop or a tab) makes a keyboard play the %1, so a console with fewer keyboards than the organ has manuals can reach all of them. Pressing it lets go of any notes held on that keyboard first. Add one for each keyboard that should be able to play this manual.\n\nThe same control added on several manuals steps the keyboard through them, one press at a time. Settings, MIDI can make General Cancel put every keyboard back where it started. Saved with this organ." = "Ein Schalter hier (ein Setzerknopf, ein Taster, ein Registerzug oder eine Wippe) lässt eine Tastatur „%1“ spielen, sodass ein Spieltisch mit weniger Tastaturen, als die Orgel Manuale hat, alle erreichen kann. Beim Betätigen werden zuerst alle auf dieser Tastatur gehaltenen Noten losgelassen. Fügen Sie für jede Tastatur, die dieses Manual spielen können soll, einen hinzu.\n\nDerselbe Schalter, auf mehreren Manualen eingetragen, schaltet die Tastatur mit jedem Druck eines weiter.
